⚡ GitHub Subfolder Push Cheatsheet

Whenever you finish a new week's notes or lab, place its index.html inside its own subfolder and push it with these 3 commands: 

# 1. Add all week folders and the root index.html
git add .

# 2. Commit your new cohort class notes
git commit -m "Add Week 2 advanced JS and Express notes"

# 3. Push to GitHub (Pages will automatically update both URLs!)
git push origin main
